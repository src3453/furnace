# 34SI22

34SI22 provides two independent one-shot sample playback channels. Select a
sample in the 34SI22 instrument; PCM8, PCM16 and SQV4 v3 H/L/L+ samples are
stored in sample RAM. SQV4 v3 uses independently decoded 63-sample fragments;
SQV4 v1/v2 is unsupported. Chip Configuration selects 1 MiB (CPT32, default) or
16 MiB (24-bit address space). In 16 MiB mode the last byte cannot be part
of a sample because the exclusive stop address must fit in 24 bits. Sample
loop points are not used.

Volume is 0–15 (2.5 dB steps; 0 is silent). Panning enables or disables each
output. Playback pitch is quantized to the nearest hardware divider:
48,000 / (DIV + 1), where DIV is 0–15. Frequencies outside this range are
clamped. Volume, frequency divider, panning and phase-reset macros are available.

The tracker uses the chip's playback functions. Recording, ADC input, AGC,
VOX and the recording functions are not implemented by this Furnace driver.
The read-only ADC registers at 0x25–0x28 report silence (zero) in Furnace,
which has no ADC input. The standalone playback core can latch ADC L/R input
on each 48 kHz tick and exposes it as big-endian signed 16-bit samples.
The playback register dump uses the chip's byte offsets and SQV4 file data is
stored unmodified. System file ID is 0xF9; instrument type is 70.

## Divider control

Effect `20xx` writes the per-channel divider, from `00` to `0F`, with a
sample rate of 48,000 / (DIV + 1) Hz. The upper four bits are ignored. It applies while playing without
restarting the sample or resetting the divider counter. The divider stays
in direct mode until the next note. A note and `20xx` on the same row use
the effect value; when an effect and the divider macro update on the same
tick, the effect wins that tick. Later macro steps can change it again.

The Freq Divider instrument macro writes absolute divider values 0–15.
While direct mode is active, pitch, arpeggio and portamento do not update
the divider. A normal note returns to automatic pitch unless a divider macro
or effect overrides it. Disabling or finishing a macro does not itself
return to automatic pitch.
