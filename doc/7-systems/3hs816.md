# 3HS816

src3453's fantasy sound chip: sixteen channels of the 3HS88PWN4 (S3HS) harmonic synthesizer, without its PCM/wavetable channels, filters, EQ or compressor. Each channel has eight operators with their own frequency ratio, volume, waveform and ADSR envelope, and one of 13 algorithms (additive, FM chains, ring modulation and direct-phase modes).

3HS816 uses the **3HS88PWN4 instrument type**, so an S3HS instrument sounds the same on both chips. It replaces the retired 3FS44U system and uses its file ID (0xFB).

## waveforms

Operators can use waves 0 to F. Waves A to D are the chip's four user waves, taken from **song wavetables 0 to 3** (32 samples each, scaled to 8-bit; a missing wavetable reads as flat). On the 3HS88PWN4 these waves come from its four WT channels instead.

## effect commands

The S3HS effects except the PCM filter (30xx to 32xx):

- `10xx` to `17xx`: set volume of operator 1 to 8.
- `18xx` to `1Fxx`: set waveform of operator 1 to 8 (0 to F).
- `20xx`: set algorithm (0 to C).
- `21xx`: set feedback amount (80 is none).
- `22xx` to `2Fxx`: set the frequency ratio of operators 2 to 8, high (even effect) and low (odd effect) byte; 1000 is 1.0.

## emulation

Both 3HS816 and 3HS88PWN4 run on an integer-only model of the chips (`src/engine/platform/sound/3hs/`), vendored from the CPT32 repository, which holds the specification (`doc/spec_3HS816.md`) and the tests against the previous floating-point 3HS88PWN4 core.
