# 3WS8PN / 3WS8PNA (S3W2)

Select **3WS8PN** or **3WS8PNA** under **Chip revision** in the chip's
configuration menu. The selection is saved in the song (`chipType=0` or `1`).
Existing songs and newly added chips default to 3WS8PN.

3WS8PNA adds two-tap linear interpolation to wavetable and unsigned 8-bit PCM
playback. Wavetables interpolate from entry 255 back to entry 0. At the final
PCM byte, the second tap uses the loop start for loops and holds the final
byte for one-shot samples. Noise playback is unchanged. This follows
[CPT32 PR #155](https://github.com/src3453/src32/pull/155) at commit
`08db622962d5729c8a59653056d74bb98502f8be`.

SQV4 decoded output is also interpolated on 3WS8PNA, following
[CPT32 PR #159](https://github.com/src3453/src32/pull/159) at commit
`3fc1b79910ee316318a497682d957a1f171c4cce`. Interpolation applies after
fragment volume and before channel volume, including across 63-sample frame
boundaries. The tap after the last decoded sample holds that sample, even
when looping; it does not blend with the loop start. Two decoded frames are
cached so looking ahead does not repeatedly restart the predictor. The
original 3WS8PN continues to play SQV4 without interpolation.

The core also implements 3WS8PNA's waveform type 5 FIFO DAC: 2048 signed
16-bit samples per channel, high-byte latch at control offset `0x0C`, low-byte
push at `0x0D`, and big-endian queued sample count at `0x0E`/`0x0F`. Full
queues drop writes; empty queues hold the last sample. One sample is consumed
every `FREQUENCY+1` steps at 48 kHz. Volume does not apply; pan does. A phase
reset write flushes the queue and held sample. The original revision ignores
FIFO writes. Furnace does not provide FIFO instruments or stream samples
through the FIFO; normal sample playback continues to use PCM/SQV4 RAM.

## SqueezVOX 4 samples

This fork supports mono SqueezVOX 4 (`.sqv` and `.sqv4`) files, version 3, in variants H, L and L+. Stereo imports are rejected: convert the
source to mono first. The file sample rate becomes the sample's C-4 rate;
import does not resample the audio.

In the Sample Editor, load the file with the normal **Open** action. To
convert an existing sample, select its **Type**:

- **SQV4H** selects the 4-bit IMA predictor inside the SQV4 container, including
  its file header and per-fragment volume bytes. It appears directly above L.
  **IMA ADPCM** remains a separate WAV-style block format.
- **SQV4L** selects the 3-bit L codec.
- **SQV4L+** selects the 3-bit L+ codec with the v3 codebook `[1,2,3,14]`.

New conversions write v3. Native v3 imports retain their codes, fragment
indices and volumes. Earlier v1/v2 containers are not supported.
The editor's waveform and preview use decoded PCM. Convert to 16-bit PCM
before destructive waveform edits, then convert back to the desired codec.
Undo/Redo and FUR save/load preserve the selected type and native H/L/L+ data.
The three SQV4 sample types are fork extensions; see `papers/format.md`.

Use **Save raw sample** with a `.sqv` or `.sqv4` filename to write a complete
mono container. The selected SQV4 type determines the codec. Non-SQV4 types export
as H through PCM re-encoding. Native H imports and uploads preserve the original
header, codes and fragment volumes without an intermediate IMA conversion. Normal **Save Sample** still exports a decoded WAV.
Import SQV4 containers with normal Open, rather than the raw-byte importer.

S3W2 chooses waveform type 4 for these compressed types and places a complete
file in its shared 1 MiB sample RAM. Start points to the header and end is an
exclusive byte pointer. The frequency register controls the playback rate.
Loop start rounds down to a 63-sample fragment boundary; loop end truncates
the container at the selected decoded sample count with canonical zero padding.
Only forward loops are supported. Compressed playback ignores PCM sample-offset
effects. Each v3 fragment carries its own initial predictor state and can be
decoded independently.

Malformed headers, unsupported versions, non-canonical padding/lengths, stereo
hardware images and invalid RAM/loop boundaries produce silence. Samples that
do not fit entirely in RAM are not loaded. SGUB export preserves compressed
bytes alongside ordinary PCM, including relocation of a second chip's bank.

The wire-format and predictor contract is defined by the CPT32 checkout's
`doc/squeezvox/squeezvox4_spec_stub.md`. The remaining S3W2 modulation behavior
in this fork is still a stub; see the SGUB export documentation.
